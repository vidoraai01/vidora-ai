VIDORA AI - LOCAL TEST SETUP (HINDI)

ZARURI:
- Node.js 20.11+, PostgreSQL, FFmpeg/FFprobe chahiye.
- Audio fingerprint ke liye Chromaprint (fpcalc) alag se install karo; Windows par FPCALC_PATH set karo.
- Real API keys/passwords ko ZIP ya GitHub par upload mat karna.

STEPS:
1. ZIP extract karo, folder me terminal kholo.
2. Verify: node --version, ffmpeg -version, ffprobe -version
3. PostgreSQL me ek database banao.
4. .env.example ko copy karke .env naam do.
5. .env me ye set karo:
   DATABASE_URL=postgresql://USER:PASSWORD@localhost:5432/DBNAME
   DATABASE_SSL=disable        <-- LOCAL Postgres ke liye ZARURI (warna "server does not support SSL" error aayega)
   SESSION_SECRET=(kam se kam 48 random characters)
   ADMIN_EMAIL=aapka email
   ADMIN_PASSWORD_HASH=(bcrypt hash)
   TRUST_PROXY_HOPS=0
   NODE_ENV=development
6. Multer security update (ek baar): npm install multer@2
7. npm ci   (agar step 6 kiya to bas: npm install)
8. npm test
9. npm start  ->  http://localhost:3000
